# たいわん中国語ノート 🧋

繁体字・ピンイン・注音（ボポモフォ）で台湾華語を学ぶ、単体HTMLの学習アプリ。
スマホのホーム画面に追加すると、アプリのように全画面で使えます。

## できること

- **カード** — 4,202語の単語カード。カテゴリとTOCFLレベルで絞り込み
- **クイズ** — 繁体字⇄日本語、ピンイン、リスニング、読解（本番形式）の6モード
- **文法** — 15レッスン。例文の音声つき
- **検定** — TOCFLのレベル別ロードマップ
- **ぴよた** — 練習するほど育つひよこ
- **発音** — シャドーイング（お手本を聞いて録音・聞き比べ）
- **リスト / きろく** — 全語の一覧と、進捗・弱点の記録

## ホーム画面に追加する

- **iPhone (Safari)** — 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)** — 右上のメニュー → 「アプリをインストール」

一度開けばオフラインでも起動します。学習のきろくは端末のブラウザ内（localStorage）に保存され、
サーバーには送られません。そのため端末をまたいだ同期はされません。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（データ・スタイル・スクリプトすべて内包） |
| `manifest.webmanifest` | ホーム画面追加用の定義 |
| `sw.js` | オフライン用のキャッシュ |
| `icon-192.png` / `icon-512.png` | アイコン |

## データについて

収録4,209語のうち4,202語が学習対象です（残り7語は元データの重複）。
例文は251語が手書き、残りは自動生成のものが不正確だったため非表示にしてあります。

元データは書き換えず、`index.html` 冒頭の上書き表で補正しています。

| 表 | 用途 |
|---|---|
| `FIX_MEAN` | 意味の追加・修正（2,061語） |
| `FIX_CAT` | カテゴリの振り直し（22語） |
| `FIX_EX` | 手書きの例文（120語） |
| `stripZhuyin` | 見出し語と例文に混ざった注音の除去 |
